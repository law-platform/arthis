第七百十八條ヲ削除シ第七百十二條第二項トシテ左ノ一項ヲ加フ
前項ノ規定ハ不法ノ原因ノ爲メニ給付ヲ受ケタル者ニモ亦之ヲ適用ス
（別案）第七百十八條ハ之ヲ削除ス
（理由）第七百十八條ニ於テハ旣成法典財產編第三百六十七條第二項ノ主義ヲ採用セリ蓋シ此主義タル羅馬以來人ノ唱スル所ニシテ或ハIn turpi Causa, melior est possidentiscausa（醜事ニ在リテハ占有者ノ利ニ歸ス）或ハNemo auditurturpitudinem suam allegans （何人ト雖モ自己ノ醜事ヲ援用スルトキハ之ヲ採用セス）或ハIn pari causa turpitudiniscessat repetitioト云ヒ現行法ニ於テモ瑞西債務法、索遜民法ノ如キハ此主義ヲ採用シ我邦ニ於テモ過般彼有名ナル角石事件ニ付キ大審院ハ此主義ヲ採用シタルカ如シ然リト雖モ本員ハ之ニ服從スルコト能ハス請ノ其理由ヲ略陳セン一、法律ハ不法行爲ヲ禁スルノ目的ヲ以テ之ニ法律上ノ强制力ヲ付セス其履行ヲ法廷ニ請求スル者アルトキハ法官ヲシテ其請求ヲ郤ケシムルニ非スヤ若シ然ラバ一旦之ヲ履行シタル後ト雖モ其履行ヲ無效トシ旣ニ給付シタルモノヲ取返スコトヲ得セシメスンハアルヘカラス然ラスシテ之ヲ取返スコトヲ許ササルトキハ不法行爲ノ當事者ハ速ニ其行爲ノ履行ヲ完了シ以テ法網ヲ脫セント謀ルコト多カルヘシ是レ間接ニ不法行爲ヲ奬勵スルモノト謂フヘシ殊ニ狡獪ナル者ハ相手方ヲシテ其履行ヲ爲サシメ自己ハ則チ自己ノ義務ヲ履行セス以テ不正ノ奇利ヲ博スルコトヲ得ヘシ況ヤ普通ノ法理ニ於テモ不法ノ目的ヲ有スル法律行爲ヲ以テ無效トスル以上ハ（九七）當事者間ニ債權債務ノ關係ヲ生セス故ニ所謂履行ハ債務ノ履行ニ非ス卽チ債務ナキ辨濟ナルニ於テヲヤ二、反對主義ヲ持テ金城鐵壁ト爲スモノハ自ラ不法行爲ヲ企テタル者カ其不法行爲ヲ理由トシテ法律ノ保護ヲ仰カント欲スルハ鐵面皮モ亦甚シト曰フニ在リ然リト雖モ其者ハ必スシモ其不法行爲ヲ理由トシテ法律ノ保護ヲ仰クニ非ス例ヘハ特定物ヲ引渡シタル場合ノ如キハ自己ノ所有物カ故ナク他人ノ許ニ在ルヲ以テ其取戾ヲ請求セシニ相手方ハ若シ之ヲ返還セサリシト欲セハ却テ不法行爲ヲ援用シテ之ヲ拒テサルヘカラス此場合ニ於テハ相手方ハ啻ニ自己ノ不法行爲ヲ理由トシテ法律ノ保護ヲ仰クノ鐵面皮ナルノミナラス其不法行爲ノ逐行ヲ法廷ニ請求スル者ナリ故ニ之ヲ保護スルハ不法ノ原因ヲ有スル法律行爲ヲ無效トセル法律ノ規定ト直接ニ矛盾スルモノト謂ハサルヘカラス殊ニ法律ノ規定ノ結果ニ因リ當事者ノ一方カ自己ノ不法行爲ヲ援用シテ其行爲ノ無效ナルコトヲ主張スルコトアルハ到底免カルルコトヲ得サル所ニシテ例ヘハ一男子カ一女子ヲ欺キ旣ニ正妻アルニ拘ハラス其女子ト結婚ノ式ヲ擧ケタル場合ノ如キ後日其男子ハ重婚ニ因リ其結婚ノ無效ナルコトヲ主張スルコトヲ得ルハ固ヨリ論ヲ俟タス又不法行爲ノ當事者ハ相手方ヨリ其行爲ノ履行ヲ請求スルニ當リ其行爲ノ不法ナルコトヲ理由トシテ其請求ヲ却クルコトヲ得ルニ非スヤ若シ然ラバ其行爲ノ不法ナルコトヲ理由トシテ旣ニ給付シタルモノヲ取戾スコトヲ得ルハ敢テ怪ムニ足ラサルナリ三、二人共謀シテ不法行爲ヲ企ツル場合ニ於テハ兩人共ニ憎ムヘシト雖モ其一人カ他ノ一人ヲ信シテ之ニ金錢其他ノ物ヲ交付シタルニ他ノ一人ハ初ヨリ不法ナルコトヲ知リテ企テタル行爲ノ不法ナルコトヲ口實トシテ其約束ヲ守ラス又其受取リタルモノヲ返還セサルハ其受取リタル者其交付シタル者ヨリ一層憎ムヘキコト多シ然ルニ反對主義ニ據レハ其理由ハ兎ニ角其結果ニ至リテハ一層憎ムヘキ者ヲ保護シテ却テ之ヨリ情ノ輕キ者ヲ酷待スルコトトナルヘキノミ以上ノ理由ニ據リ本員ハ第七百十八條ニ取リタル主義ニ左祖スルコト能ハス蓋シ羅馬法ニ於テハ前ニ揭ケタル格言行ハレ正ニ反對主義ヲ取リタルカ如キモ佛國ニ於テハ明文ナキニ拘ハラス今日ノ學說、裁判例共ニ本員等ノ主義ニ傾向セルカ如シ（Calmet de Santerre, Cours analytique de code civil, t.v. n°＝49 bis IV; Maroa, De explication du code civil, t.
